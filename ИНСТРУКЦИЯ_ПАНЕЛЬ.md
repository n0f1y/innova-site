# Как вносить правки в сайт (панель управления Sanity)

Тексты, цифры, контакты, услуги, эксперты, кейсы и статьи правятся в панели управления
(Sanity Studio). Менять код или файлы для этого не нужно.

> Старая инструкция `ПРАВКИ.md` (правка файлов вручную) больше не актуальна: её заменяет эта.

## Для владельца сайта

1. Откройте адрес панели (его пришлёт разработчик, вид: `https://название.sanity.studio`).
2. Войдите с почты или аккаунта Google, который добавлен в проект.
3. Слева выберите раздел, внесите правки и нажмите зелёную кнопку **Publish** («Опубликовать»).
4. Через минуту изменения появятся на сайте. Перезагружать или собирать ничего не нужно.

### Что в каких разделах

| Раздел в панели | Что на сайте |
|---|---|
| **Настройки сайта** | Название компании, условия вступления, тарифы (с примечанием), льготная аренда, адрес, телефон, e-mail, Telegram и VK |
| **Услуги** | 8 карточек: название, список «что входит», стоимость, фото при наведении |
| **Эксперты и менторы** | Карточки экспертов и фильтр по направлениям. Блок скрыт, пока нет ни одного эксперта |
| **Кейсы резидентов** | Истории успеха с цифрами. Блок «Кейсы и резиденты» скрыт, пока нет ни кейсов, ни видео |
| **Видео-отзывы** | Плитки с видео в блоке «Кейсы и резиденты» |
| **Блог и новости** | Гайды, статьи и новости со своими страницами |

Блоки «Кейсы и резиденты», «Видео-отзывы» и «Эксперты и менторы» появятся на сайте сами, как только в панели будет добавлена первая запись. Тексты «Почему выбирают нас», «Миссия», «Основные виды деятельности» и «Чем бизнес-инкубатор может быть полезен» лежат в файле `src/data/content.ts` и меняются разработчиком.

### Частые действия

- **Заменить цифру или текст:** открыть «Настройки сайта», поменять поле, Publish.
- **Добавить эксперта:** «Эксперты и менторы» → Create (плюс), заполнить имя, направление, специализацию, опыт, фото → Publish. Удалить: открыть карточку → меню «…» → Delete.
- **Заменить фото услуги:** «Услуги» → нужная услуга → поле «Фото карточки» → загрузить файл. Кликнув по фото, можно сдвинуть точку фокуса («Hotspot»), чтобы в кадре осталось главное.
- **Если на светлом фото плохо читается текст:** в услуге выберите «Затемнение фото» → «Плотное».
- **Добавить видео-отзыв:** «Видео-отзывы» → Create → подпись и **ссылка на ролик** (адрес из браузера: YouTube, VK Видео, Rutube или Vimeo; сам видеофайл загружать не нужно) → при желании обложка → Publish. Видео запускается по нажатию. Если ссылка с другой площадки, плитка откроет её в новой вкладке. Пока видео нет, блок «Видео-отзывы» на сайте не показывается.
- **Выложить статью, гайд или новость:** «Блог и новости» → Create → выбрать раздел (Статья, Гайд, Новость инкубатора) → заголовок → **адрес страницы** (нажмите «Generate») → **текст** (заголовки, списки, жирный, ссылки, картинки) → дата для новости → Publish. Когда заполнены адрес и текст, заголовок в списке на сайте становится ссылкой на отдельную страницу. Если текста нет, заголовок виден, но не открывается. Так сейчас стоят три темы гайдов.
- **Добавить Telegram, VK, телефон, e-mail:** «Настройки сайта» → блок «Контакты» → заполнить поля → Publish. Пустые поля на сайте не показываются.
- **Порядок карточек** задаёт поле «Порядок» (у услуг «Номер услуги»): чем меньше число, тем раньше.

Если в поле стоит условное значение (например, цена «По запросу»), оно так и показывается на сайте. Замените его настоящими данными.

## Для разработчика: однократная настройка

1. Создайте проект на https://www.sanity.io/manage (датасет `production`, доступ «Public»). Скопируйте **Project ID**.
2. Панель:
   ```bash
   cd studio
   npm install
   copy .env.example .env      # впишите SANITY_STUDIO_PROJECT_ID (и при желании SANITY_STUDIO_HOST)
   npx sanity login
   npm run seed:make           # собрать seed/data.ndjson из src/data
   npm run seed:import         # загрузить стартовый контент и фото
   npx sanity deploy           # опубликовать панель на *.sanity.studio
   ```
3. Сайт: добавьте переменные окружения (локально в `.env.local`, на Vercel в Settings → Environment Variables):
   ```
   NEXT_PUBLIC_SANITY_PROJECT_ID=<Project ID>
   NEXT_PUBLIC_SANITY_DATASET=production
   ```
4. Пригласите владельца в проект: sanity.io/manage → проект → Members → Invite (роль Editor).
5. Передеплойте сайт на Vercel, чтобы переменные подхватились.

Без переменных `NEXT_PUBLIC_SANITY_*` сайт показывает локальные данные из `src/data/` (запасной вариант).
Правки из панели обновляют сайт не позже чем через 60 секунд (`REVALIDATE` в `src/lib/sanity.ts`).

## Важно знать

- Формы «Оставить заявку» и «Подписаться» пока демонстрационные: данные никуда не отправляются.
- Не храните в панели конфиденциальные данные: всё, что опубликовано, видно на сайте.
- Если добавить 9-ю и следующие услуги, у них будет нейтральная иконка.

## Безопасность сайта (для разработчика)

- Заголовки защиты заданы в `next.config.mjs`: политика загрузки ресурсов (CSP), запрет встраивания сайта в чужие страницы, защита от подмены типа файла, ограничение браузерных функций, HSTS. Политика разрешает только свой домен, картинки из `cdn.sanity.io` и видеоплееры YouTube (nocookie), VK, Rutube, Vimeo. Новый источник (аналитика, шрифты, новый плеер) нужно добавить в этот список, иначе браузер его заблокирует.
- Ссылки из панели (соцсети, видео) проходят через `src/lib/safe-url.ts`: допускаются только http(s), mailto, tel и внутренние адреса.
- Видео встраиваются только с известных площадок (`src/lib/video.ts`); остальные открываются обычной ссылкой.
- Ключей и паролей в проекте нет. Идентификатор проекта Sanity не секрет. Если понадобятся токены (форма заявок, вебхуки), хранить их только в переменных окружения или менеджере секретов хостинга, не в коде.
- Раз в месяц запускайте `npm audit --omit=dev` в корне и в `studio/` и обновляйте Next.js в рамках ветки 15.x. Остаточные замечания во вложенном `postcss` закрывает только переход на Next 16.
- Доступ в Sanity: всем участникам включить двухфакторную защиту, приглашать только нужных людей и отзывать доступ уходящим.
